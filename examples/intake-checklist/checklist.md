# Use Case Intake Checklist

Edit this file to change the follow-up wording. The checks reference fields
by index, not by question text — so you can rephrase questions freely without
touching `checks.json`.

## Project Context

| Question | Expected |
|---|---|
| What problem are we solving? | one paragraph |
| Who feels the pain today? | role / team |
| How is this measured? | revenue / cost / risk / speed |

## Data Landscape

| Question | Expected |
|---|---|
| Where does the data live today? | warehouse / bucket / API |
| How fresh does the answer need to be? | real-time / hourly / daily |

## Success Criteria

| Question | Expected |
|---|---|
| What does "done" look like? | concrete acceptance test |
